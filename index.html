// MULTI-PROVIDER AI CODING AGENT · BUILT FOR ROBLOX & GAME DEVS

A single HTML file that behaves like a full AI coding agent, built for Roblox and game developers. It routes requests across three LLM providers with automatic failover, validates every piece of generated code before showing it to you, and stays fully portable, no build step, no server, just one file.

What it does
  • Multi-provider failover: Groq, OpenRouter, and Cerebras with automatic key rotation.
  • Artifact panel: generated scripts render in a live preview pane, separate from chat.
  • Two-layer sandbox self-check: all generated code validated before it's shown.
  • Multi-round tool calling: calls tools, reads results, keeps reasoning in one turn.
  • Web search & image generation: integrated Tavily lookups plus AI images.
  • Hardened against XSS: global output-escaping pass on rendered content.

// REAL-TIME EDGE AI · RASPBERRY PI 5 · ON-DEVICE ML · NO CLOUD

A computer vision system that classifies plastic bottles by resin type (PET, HDPE, LDPE, PP, UNCLASSIFIED) in real time and drives mechanical actuators to physically sort them. Runs entirely on a Raspberry Pi 5 with no cloud dependency: model training, embedded deployment, hardware integration, and prototype validation, end to end.
